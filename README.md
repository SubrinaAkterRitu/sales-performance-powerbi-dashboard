# Sales Performance Dashboard Using Power BI
This repository contains a Power BI sales dashboard designed to track sales performance, revenue trends, customer insights, and business KPIs.

## Project Overview
The dashboard helps convert sales data into clear, actionable insights. It is designed for sales managers, business analysts, and management teams to monitor business performance and make data-driven decisions.

## Key Metrics Covered
- Total sales
- Revenue trend
- Sales performance
- Customer analysis
- Product/category performance
- Regional or segment-wise performance
- Monthly business KPIs

## File Included
- sales-performance-dashboard.pbix

## Tools Used
- Power BI
- Power BI Desktop
- Data visualization
- Business intelligence reporting

## Use Case
This dashboard can be used to monitor sales performance, identify growth trends, compare business segments, and support management reporting.

## How to Use
1. Download the `.pbix` file.
2. Open it using Power BI Desktop.
3. Review the dashboard pages and visuals.
4. Replace or refresh the dataset if needed.
5. Customize KPIs, charts, and filters based on business requirements.
